# Requirements for RUNNING THE APP.
#
# The app is a reader: it loads the precomputed parquet files in data/processed
# and draws them. It trains nothing, so it does not need lightgbm, scikit-learn
# or statsbombpy. Those belong to the pipeline -- see requirements-pipeline.txt.
#
# Lower bounds rather than exact pins, deliberately. A pin ties the install to
# whatever Python the host happens to offer, and a pin with no matching wheel
# forces a source build that then fails. Floors let the resolver pick the newest
# release that does have a wheel for the host interpreter.

# pandas is capped below 3.0: the code was written against the 2.x API, and
# 2.3.x still ships wheels for current Python. numpy 2.x is fine -- checked for
# the aliases numpy 2.0 removed, none are used.
# streamlit is capped below 1.50: the app calls use_container_width ~17 times,
# which 1.50+ deprecates with removal announced. Staying on the API generation
# the app was written for matters more than being current, since this gets
# demoed live. Pure-Python package, so the cap costs nothing at install time.
streamlit>=1.40,<1.50
pandas>=2.2,<3
numpy>=1.26,<3
pyarrow>=17
matplotlib>=3.8
mplsoccer>=1.2
plotly>=5.20
